# 首页灵感推荐区产品&研发实现方案 v5（评审版）

> 日期：2026-06-16  
> 配套 PRD：`docs/AI互动课件首页灵感推荐区_PRD_v5_评审版.md`  
> 配套数据：`docs/灵感推荐区_研发可直接入库种子数据_v1.json`

## 1. 目标

把 `creative-shrimp-suite-v1.0` 中已沉淀的 action 玩法模板，产品化为首页「灵感推荐区」。研发不需要阅读原始能力包，只需要使用本方案和种子 JSON 即可完成 P0。

P0 要解决三件事：

1. 老师能快速看懂“这是什么课堂互动玩法”。
2. 老师能通过真实 HTML 示例理解玩法效果。
3. 老师套用后，只补教学内容，就能把真实玩法 prompt 带进正常生成链路。

## 2. 数据来源与边界

| 数据 | 使用文件 | 原始来源 | P0口径 |
| --- | --- | --- | --- |
| 首页分类 | `categories.tabs` | `templates-ready/action/INDEX.md` | 精选 + action 8类 |
| 首页玩法 | `playways` | INDEX 中正式 40 条 | 不纳入未登记文件 |
| 玩法 prompt | `playways[].templatePrompt` | 最高版本 markdown 全文 | 套用后真实发送 |
| 只读示例 | `examples` | 当前 demo HTML 资产 | 7个示例入口，3个为真实新示例 |
| 年龄筛选 | `categories.ageBands` | 文件名年龄 | 6-10岁、10-14岁 |

补充说明：`templates-ready/action` 目录下确实还有未登记在 INDEX 的文件，例如 `04-make-a-word` 和个别 v4 补充文件。本期为保证评审口径清晰，P0 不纳入首页。后续如果产品确认，可作为第二批扩展。

## 3. 首页分类实现

| tab | 是否真实分类 | 过滤规则 | 展示说明 |
| --- | --- | --- | --- |
| 精选 | 否 | 按 priority 取前16条 | 默认推荐池 |
| 跳跃障碍类 | 是 | `playway.category === "jump_obstacle"` | 跳跃障碍 + 落地答题 |
| 竞速赛跑类 | 是 | `playway.category === "race_speed"` | 答对加速 + 答错减速 |
| 捉迷藏伪装类 | 是 | `playway.category === "hide_seek"` | 寻找伪装的知识元素 |
| 团队协作类 | 是 | `playway.category === "team_coop"` | 多人协作答题 |
| 生存竞技类 | 是 | `playway.category === "survival_arena"` | 答对生存 + 答错复习 |
| 对战推理类 | 是 | `playway.category === "battle_reasoning"` | 答题对战 + 逻辑推理 |
| 限时解谜类 | 是 | `playway.category === "puzzle_rush"` | 限时完成知识拼装 |
| 淘汰晋级类 | 是 | `playway.category === "elimination"` | 多轮晋级，末位淘汰 |

前端类型：

`featured | jump_obstacle | race_speed | hide_seek | team_coop | survival_arena | battle_reasoning | puzzle_rush | elimination`

## 4. 推荐与筛选逻辑

默认态：

1. 默认 tab：精选。
2. 默认年龄：全部年龄。
3. 默认展示：前 8 张卡片。
4. 点击“换一换”：展示下一批 8 张，末尾循环。

筛选伪代码：

```ts
const byTab = activeTab === 'featured'
  ? playways.sort(byPriority).slice(0, 16)
  : playways.filter(item => item.category === activeTab);

const visible = byTab.filter(item => hasAgeOverlap(item.ageText, activeAgeBand));
const batch = getCycledBatch(visible, batchIndex, 8);
```

年龄判断：解析 `ageText` 中的数字范围，和当前年龄段有交集即展示。

## 5. 卡片展示

每张卡片展示：

1. 年龄 + 玩法类型。
2. 玩法名。
3. 一句话说明。
4. 课堂流程前 4 步。
5. 最多 3 个标签。
6. 看玩法示例。
7. 套用玩法。

不展示：玩法总数、内部来源、sourceRefs、长 prompt、风格选择、+1、换题面、批量关卡、换风格等无法让老师立即理解的标签。

## 6. 看玩法示例

点击“看玩法示例”后：

1. 使用全局弹层，渲染到 `document.body`。
2. 层级高于侧边栏和灵感助手。
3. 左侧 iframe 展示只读 HTML 示例。
4. 右侧展示老师能理解的信息：示例说明、适合内容、课堂流程、可以怎么改成你的课。
5. 不提供下载、打开新窗口、编辑、一键同款。
6. 点击“套用这个玩法”关闭弹层，并执行套用玩法逻辑。

## 7. 套用玩法

套用后输入框进入结构化草稿：

1. 顶部是“教学内容”主输入区，老师只需要填年级、知识点、题目范围或课堂要求。
2. 下方是已套用玩法摘要，展示玩法名、类型、年龄、流程和可替换内容。
3. “生成提示词预览”默认折叠，展开后渲染真实 `templatePrompt` markdown。
4. 切换玩法时保留教学内容，只替换玩法块。
5. 发送后走原有需求确认和生成流程。

内部纯文本协议保持：

```text
教学内容：{老师填写内容}

<已套用玩法>
玩法名称：{title}
玩法类型：{typeLabel}
适用年龄：{ageText}
适合内容：{suitableFor}
...
玩法要求：
{templatePrompt}
</已套用玩法>
```

## 8. 验收清单

| 场景 | 验收标准 |
| --- | --- |
| 首页分类 | 展示精选 + 8个 action 分类，不再展示语文/数学/英语等学科 tab |
| 分类数量 | 8类数量分别为 6/6/6/4/4/4/6/4 |
| 年龄筛选 | 只展示全部年龄、6-10岁、10-14岁 |
| 套用玩法 | 回填结构化输入框，保留老师已填内容 |
| 切换玩法 | 不叠加旧玩法块，只替换玩法信息和 templatePrompt |
| Prompt预览 | markdown 被渲染，不能出现满屏未渲染的 **加粗符号** |
| 示例弹层 | 侧边栏、灵感助手都在遮罩下层 |
| 数据追溯 | 任意卡片都能在 JSON 中找到 sourceRefs 和 templatePrompt |
| 构建 | `npm run build` 通过 |
