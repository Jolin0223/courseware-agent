# 视频方案确认与生成卡复用：实现与验证

2026-09-14。依据用户批准的[实施前评审](视频方案确认与生成卡复用_评审.md)，在独立分支 `codex/wukong-video-h5-agent-demo` 中完成。本地入口仍为 http://127.0.0.1:4186/ 。

## 本轮结果

教师仍从原输入框发起任务。视频模式的流程为：

**教学方案确认 → 图片与配音生成 → 自动整理视频方案 → 一次确认画面、配音与视频方案 → 视频生成 → 互动页面组装 → 原整课预览和发布。**

没有增加独立工作台，也没有要求教师逐段确认。原素材确认区扩充为视频方案确认。

| 批注与补充 | 实现 |
| --- | --- |
| 入口图标、示例折行 | 普通互动课件使用游戏手柄图标；视频示例显示短标题，点击仍填完整需求；1137px 视口下三例同一行 |
| 风格与音色 | 视频输入保留画面风格，音色标为“旁白音色”；有对白的角色在教学方案中分别设置。生成期间锁定偏好，避免和已确认方案冲突 |
| 方案标题 | 视频模式显示“视频互动课件设计方案确认”，普通 H5 标题保留 |
| 三种内容形式 | 互动页面、视频、视频＋互动分别使用图标及蓝、紫、青色小标签；平台主按钮继续使用原品牌色 |
| 多余时长说明 | 删除批注指定的说明 |
| 图片、音频卡 | 直接复用 ImageGenerationPanelV2 和 AudioGenerationPanel，增加可选素材数据及预览回调；普通 H5 默认行为保留 |
| 进度条 | 图片 4px、音频 3px；按实际完成项显示百分比，完成数与百分比一致 |
| 音频 | 按旁白和角色分组；真实 audio 播放、暂停、结束、失败状态；实际媒体时长，不使用虚构时长 |
| 生成视频的位置 | 确认后追加新的生成消息，视频进度与片段卡同处；重做时原消息保存快照，刷新按保存的先后序号恢复顺序 |
| 视频前规划 | 每段绑定起始图片、配音、秒数、动作、结束方式与生成描述；结尾参考图可选；生成描述折叠查看、编辑 |
| 材料变更 | 依赖的图片、配音、声音设置或教学方案改变，会使相关镜头方案失效；重新确认前不能启动视频任务 |
| 独立交互素材 | 独立徽章、道具和互动点读音频不会默认触发视频重生；明确选择为镜头参考时按实际引用处理 |
| 历史与发布 | 旧 HTML 与发布记录保留；新版本进入原预览和发布弹窗，不自动覆盖已发布版本 |

## 内容来源与原型边界

- 教学附件仍为原第 5—13 页的 9 张图片，界面编号 01—09。
- 复用悟空原大纲、素材、视频和完整生成描述；规划层依据本次编辑的动作、声音、时长及结束条件组装提示词。
- 25 条音频的时长由本地原文件经 ffprobe 读取，保存在 audioDurations.json。开场旁白合计约 13.4 秒；任务邀请角色配音约 4.5 秒，任务卡点击点读不计入这段角色视频。
- mission、move、outro 使用已有参考图；opening、arrival 的原型起始图片提取自已有视频首帧，保存在 public/wukong/planning。它们是用于演示流程的固定素材，经过“准备画面”加载后才出现，不代表调用模型生成了新首帧。
- 初次加载节奏：教学方案约 2.4 秒、图片与配音约 10.5 秒、视频规划约 3.6 秒、视频约 16 秒、组装约 4.5 秒；等待确认时间另计，非生产耗时承诺。
- 修改文字、音色和镜头配置可演示规划、校验及确认流程；生成动作继续回放已有媒体。**未接入真实图像、视频、TTS 生成或远端发布服务，修改配置不会重拍、重录原成品。**
- 上传替换与独立图层播放设置沿用已有能力。原素材文件和原始课件未改动。
