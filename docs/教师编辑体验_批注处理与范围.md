## 新增角色的范围判断

“加一个铁扇公主”是教学内容变化，不能靠新增音色行完成。现有每场只有一组“讲述者 + 台词”，完整支持同场多角色需要中等范围的数据与流程调整。

建议的具体范围：

1. 在教学流程中新增角色，并选择在哪些场景出现、承担什么作用；每个场景支持多条“角色 + 台词”。角色姓名由老师填写，不固定为案例人物。
2. 根据这些出场安排生成角色形象素材和独立音色设置；老师确认后才准备图片与配音。
3. 每段视频仅引用实际出场角色的形象和台词。修改或删除角色时，仅使相关素材、视频方案失效，回到对应确认节点。
4. 用真实新增角色图片与音频演示；需要新增表演的视频也需真实产出。现有悟空视频不能代表铁扇公主已经出场。

本轮完成已有角色到教学环节的回链，没有直接扩建多角色剧情系统或伪造铁扇公主素材。新增角色这部分需在上述范围确认后再实施。
