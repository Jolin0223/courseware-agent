## 保存与取消

- 输入 `@` 或点击引用按钮，在右侧选择本场或本课素材；写入描述的同时更新实际引用。
- 视频参考与配音可在同页选择；首尾帧为选填项。配音时间仍由系统安排，不恢复三个音频秒数框。
- 资源编辑内“应用到场景”先进入本场草稿；返回场景保留已应用修改，最后“保存本场修改”统一提交。
- 取消整场同时丢弃本次场景与资源草稿，不能留下部分保存的媒体修改。
- 共享素材保留原资源编辑中的使用位置提示；保存后更新真实依赖的场景与视频状态。成品编辑阶段“默认只改本场”的独立版本规则另见下方实现。
- 视频/音频变动重新校验引用及音长；V33 原始描述、15 秒视频及未编辑配音的时间安排保留。
