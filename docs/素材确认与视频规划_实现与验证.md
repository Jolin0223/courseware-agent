# 素材确认、视频规划与场景交付：实现与验证

2026-09-14｜已按确认方案实施于独立视频原型，入口：http://127.0.0.1:4186/ 。

## 当前教师流程

选择视频互动课件、描述需求 → 教学方案确认 → 图片与配音生成 → **确认画面与配音** → 视频方案规划与确认 → 6 段视频生成 → 下方合成卡 → 按 12 个教学场景展示的互动课件卡 → 原预览与 iTeach 发布入口。

- 视频输入框隐藏画面风格、单一课件音色，避免与方案重复设置。普通 H5 保持原入口；普通 H5 的音色不会自动带入视频角色。
- 教学目标保持可见，其他设置分为“教学流程 / 画面与配音”。流程为紧凑列表，支持鼠标和触控指针拖动，保留上下移动按钮。
- 复用平台图片、音频生成卡，在卡片标题处分别提供“修改图片 / 修改配音”；生成完不会直接规划视频。
- 视频方案默认只显示本段使用的素材。生成描述常显，支持插入图片/配音引用；配音显示实际台词与对应画面，可试听、更换；播放时间自动安排。首尾帧置顶并排且均可空。
- 图片参考与首尾帧分开：参考图有用途和使用范围；选择器默认“本场相关”，需要时才打开全课素材。人物、互动道具不自动进入首尾帧。
- 视频生成、剪辑合成、最终课件分别留下记录。场景卡可展开全部场景、进入对应场景并切换，整课继续使用原预览与发布弹窗。

## 真实素材映射

本例显示 12 张生成图片、25 条真实旁白/角色音频、6 个真实视频；上传教学材料仍为 9 张。6 个视频是制作资产数量，12 个场景是教学内容数量，其中洞口环境视频在互动场景中使用。

| 搬石邀请 | V30 搬石原首帧 / 无 | 无 | 0.6 秒，悟空 |

- 新增的 5 份参考素材逐字节匹配原制作包，2 处共享帧映射同时校验；[来源和 SHA-256 清单](video-production-reference-manifest.json)。
- 原 135 份媒体校验通过，所有示例媒体地址返回正确内容；视频仍用已经确认的 V32 成品。
- 通用数据结构在 `model.ts`，案例映射在 `wukongInputs.ts`，不会把悟空或雨字徽章变成平台固定字段。

## 状态与历史课件

素材与视频方案分别保存确认签名。素材变化会使相关视频失效，重新确认后再规划；无关互动叠加图不会让其他视频全部重做。编辑其他参数时保留老师写过的视频描述与配音安排。

旧生成记录及课件版本保留自己的素材、场景和配音快照。已完成的历史 HTML 不改写，已发布版本不被新草稿覆盖。新生成版本使用独立 `public/wukong/lesson-v4.html`，原 `index.html` 和 V32 来源不改。

新入口接收场景顺序，并在继续播放时使用该顺序。已确认文件的画面内部内容仍由真实视频本身决定；调整视频生成描述不会在本地凭空生成一段不同表演。

## 原型边界

这是使用真实媒体演示产品流程的本地原型，未接入模型生成或远端 iTeach 服务。“重新生成”仍展示短时等待并回用样例成品；图生图与文生图保存各自的生成方式和参考素材，不调用真实模型。原配音安排可导出真实文件、起点和截取范围供新课件播放，重新配音后的精确口型及真正的视频重拍仍需后端实现。

本轮没有重新验收全部原学生端教学操作，也不把已有包体或历史 lint 问题扩成无关重构。
