# AI互动课件生产Agent 接入 iTeach 蓝橙视觉规范

## 1. 产品视觉定位

AI互动课件生产Agent 接入 iTeach 小学工作台后，视觉定位为“面向老师的智能课件生产 Agent”。它需要承接 iTeach 的清爽工作台秩序，同时保留 AI 产品应有的智能感、科技感和生成感，不必完全弱化成传统后台工具。

关键词：

| 关键词 | 说明 |
| --- | --- |
| 工作台承接 | 以 iTeach 小学工作台的白底、浅蓝侧栏、清晰边框和标准蓝操作为基础。 |
| 智能科技感 | 保留蓝青科技感，但常规渐变使用更柔和的 `#35DDE7`；`#00FFF6` 仅作为极小面积高亮信号备用。 |
| 高效清爽 | 页面层级清晰，卡片边框轻，阴影轻，减少装饰性背景。 |
| 教研可信 | 保持专业、稳定、可长期使用的工具感，避免过度卡通化和过度营销化。 |

## 3. 蓝色和橙色使用规则

| 颜色 | 使用范围 | 禁止范围 |
| --- | --- | --- |
| 蓝色 | 导航、选中态、普通主按钮、卡片选中、链接、筛选选中、输入框 focus。 | 不要让所有强调都变成蓝色，避免缺少智能识别点。 |
| 橙色 | 发布、更新发布、套用玩法、采用补全等“明确创作动作”。 | 不要用于普通筛选、导航、说明文字、一般状态标签；输入框发送按钮因与主输入容器绑定，使用蓝青渐变。 |
| 青色 | `#35DDE7` 是常规智能感辅助色，用于蓝青主渐变、生成进度、灵感助手、AI 状态点、局部高亮。 | 不要把整页背景、整块卡片或大面积文字都铺成高亮青。 |
| 大面积蓝青面 | 结果卡片头部等大面积色块使用更柔和的 `--agent-surface-gradient`，青色降亮度到 `#35DDE7` 附近。 | 不要直接把 `#00FFF6` 铺在大面积卡片头部，否则白字和图标可读性会下降。 |

判断标准：

- 用户要“发布/套用/采用补全”时，用橙色；输入框里的发送按钮用蓝青渐变，保持和输入容器、智能生成语境一致。
- 用户在“浏览/筛选/查看/选择页面结构”时，用蓝色。
- 用户看到“AI 正在理解、生成、推荐、智能辅助”时，可以用柔和蓝青渐变；`#00FFF6` 只用于极小面积点亮。
- 需要表达警告时，不直接复用动作橙，应使用独立警告色并配合文案。

## 4. 按钮规范

| 按钮类型 | 样式 | 示例 |
| --- | --- | --- |
| 一级结构按钮 | 蓝青渐变，白字，8px 圆角。 | 新建任务、主要导航入口。 |
| 创作动作按钮 | 橙色轻渐变，白字，8px 圆角。 | 套用玩法、采用补全、发布、更新发布。 |
| 次级按钮 | 白底、主题边框、蓝色文字。 | 查看说明、全屏预览、取消。 |
| 图标按钮 | 透明或白底，灰蓝图标，hover 后浅蓝底。 | 上传图片、上传文件、展开/收起。 |
| 禁用按钮 | 浅灰底、灰色文字、无阴影。 | 生成中不可点、历史版本不可编辑。 |

按钮注意事项：

- 不要在同一区域同时出现多个高饱和渐变按钮。
- 同一行中只允许一个最强主按钮。
- hover 阴影不超过 `0 8px 18px rgba(...)`，不要使用大范围发光。
- 按钮圆角以 6-8px 为主，不使用过度胶囊化，除非是筛选 chip。

## 5. 卡片规范

| 属性 | 规范 |
| --- | --- |
| 背景 | `#FFFFFF`，不使用彩色渐变卡片底。 |
| 边框 | `1px solid var(--agent-border)` 或普通 `#E2E8F0`。 |
| 圆角 | 常规卡片 10px，较大容器 12-16px。 |
| 阴影 | 默认极轻或无；hover 可用 `0 10px 26px var(--agent-shadow)`。 |
| 选中态 | 蓝色边框 + 浅蓝背景或轻阴影。 |
| 内容密度 | 教研工具类页面保持信息密度，不做大面积空洞装饰。 |

卡片禁止事项：

- 不要用大面积蓝青渐变做卡片背景。
- 不要多层卡片套卡片。
- 不要让 hover 位移超过 1-2px。

## 6. 侧边栏规范

| 模块 | 规范 |
| --- | --- |
| 背景 | 浅蓝 `#EAF5FF`，接近 iTeach 工作台侧栏。 |
| Logo | 不替换 logo。使用当前产品 logo 规则。 |
| 新建任务 | 蓝色轻渐变，白字。它是结构主入口，不用橙色。 |
| 普通导航 | 灰蓝文字；选中后白底、蓝字、左侧蓝色边线。 |
| 历史会话 | 保持轻量列表，不使用重卡片。 |
| 配色方案入口 | 仅 Demo 使用，默认折叠，正式产品不展示。 |

## 7. 表单和输入框规范

| 类型 | 规范 |
| --- | --- |
| 主输入框 | 白底，默认主题边框，focus 后蓝色边框或蓝色轻渐变边框。 |
| 搜索框 | 白底、浅边框、左侧搜索图标，focus 后蓝色边框。 |
| 标签输入 | 白底，标签使用浅蓝/浅橙底，边框轻。 |
| 下拉选择 | 白底，hover 浅蓝，选中态蓝色文字。 |
| 上传入口 | 图标按钮为灰蓝；hover 用浅蓝底。 |

表单注意事项：

- 输入区不要出现过强阴影。
- 智能补全提示可以用浅橙底，因为它属于“创作动作辅助”。
- 普通说明提示用灰蓝文字，不用橙色。

## 8. 状态反馈规范

| 状态 | 色彩 |
| --- | --- |
| 成功/当前发布 | 蓝色或系统成功色，小面积使用。 |
| 历史发布 | 灰蓝色，降低权重。 |
| 未发布草稿 | 橙色文字或浅橙提示，小面积使用。 |
| 已下架/已删除 | 红色或灰红，明确不可用。 |
| 生成中 | 蓝青进度为主，进度末端使用 `#35DDE7`；`#00FFF6` 仅用于极小面积状态光点。 |
| 禁用 | 浅灰底、灰字，不使用蓝/橙。 |

状态反馈注意事项：

- 不要使用绿色浅底作为蓝橙主题的默认选中态。
- Toast 文案简短，颜色跟随状态，不做大面积彩色块。
- 进度反馈保持统一：蓝色表达流程推进，橙色表达关键生成动作。

## 9. 生成流程组件规范

| 组件 | 规范 |
| --- | --- |
| 欢迎页标题 | 黑色/深蓝文字，关键词可用蓝色强调，不使用多色渐变大标题。 |
| 主输入框 | 页面视觉中心，边框清晰，发送按钮用蓝青渐变，避免在输入框内部出现突兀橙色。 |
| 灵感推荐区 | 白底或极浅蓝白底，轻边框，轻阴影；分类 tab 蓝色选中。 |
| 灵感卡片 | 白底、轻边框、10px 圆角；“查看说明”用蓝色次级按钮，“套用玩法”用橙色动作按钮。 |
| 灵感助手 | 入口需要可见，但不要使用呼吸发光；可以使用固定按钮 + 轻蓝/橙点缀。 |
| 生成进度 | 蓝色步骤进度为主，当前执行步骤可有轻微强调。 |
| 结果卡片 | 白底，状态清晰；查看/预览用蓝色，发布/更新发布用橙色。 |
| 预览面板 | 工具栏白底，设备 tab 选中用浅蓝，不使用浅绿。 |

## 10. 禁止事项

| 禁止项 | 原因 |
| --- | --- |
| 不要替换 logo | 视觉升级仅处理配色和组件规范，不改品牌识别。 |
| 不要把主题切换做成正式功能 | 配色选择器只用于 Demo 和评审，正式产品不展示给老师。 |
| 不要滥用渐变 | 蓝青渐变用于主按钮、智能入口、生成状态；橙色渐变用于创作动作。不要把所有容器都做成渐变。 |
| 不要大面积铺满高亮青 | 常规蓝青渐变使用 `#35DDE7`，`#00FFF6` 只应用在关键智能信号的极小面积上，不要整页、整卡片、整段文字铺满。 |
| 不要混用绿色选中态 | 蓝橙主题中选中态统一使用浅蓝。 |
| 不要把橙色用于所有强调 | 橙色只代表创作动作，不代表普通选中。 |
| 不要重构页面结构 | 本次是接入 iTeach 前视觉升级，不改变业务链路和页面信息架构。 |
| 不要使用过重阴影 | 工作台产品应稳定、轻量，阴影只用于 hover 或弹窗层级。 |
| 不要出现多套按钮风格 | 同类按钮在首页、我的作品、发布弹窗、预览面板中需保持一致。 |
