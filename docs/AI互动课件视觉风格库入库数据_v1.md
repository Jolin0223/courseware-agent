## 1. 入库字段

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| id | string | 风格唯一标识，前端和服务端统一使用 |
| name | string | 展示给老师看的风格名称 |
| type | enum | `base` 基础风格；`enhancement` 增强质感标签 |
| desc | string | UI 卡片短说明 |
| prompt | text | 注入到生成链路的完整视觉风格提示词 |
| sourceFile | string | 来源文档，仅研发入库追溯用，不在用户侧展示 |
| sourceKey | string | 来源段落或代码，如 `style-1`、`+jelly`、`kidslogic` |

## 2. 产品使用规则

- 首页灵感推荐区只展示互动玩法，不展示独立风格库。
- 需求确认卡的「画面和反馈」区可选择画面风格，选择后替换上一条风格 prompt，不追加多条。
- 生成后预览页的「调整画面风格」用于生成一个新版本，保留当前玩法和内容，只重做视觉表现。
- 基础风格可单独使用；增强标签建议叠加在已有基础风格上。首期 demo 允许直接选择增强标签，用文案说明“在当前基础风格上叠加”。

## 5. 首期实现建议

- 数据表可命名为 `visual_style_presets`。
- 前端按 `type` 分组展示：基础风格、增强质感。
- 老师选择后，把 `prompt` 注入到需求确认卡或新版本生成请求。
- 若后续支持组合选择，建议字段增加 `compatibleBaseStyleIds` 和 `maxEnhancementCount`，默认最多 2 个增强标签。
