# 首页灵感推荐区产品&研发实现方案 v5（评审版）

> 日期：2026-06-16  
> 配套PRD：`AI互动课件首页灵感推荐区_PRD_v5_评审版.md`  
> 配套数据：`灵感推荐区_研发可直接入库种子数据_v1.json`

## 1. 目标

把 `creative-shrimp-suite-v1.0` 中已经沉淀的课堂互动玩法，产品化为首页「灵感推荐区」。研发不需要阅读原始能力包，只需要使用本方案和种子JSON即可完成 P0 实现。

P0 目标不是做资源库，也不是做复杂推荐算法，而是让老师完成三件事：

1. 在首页快速找到一个适合知识点的互动玩法。
2. 通过真实HTML只读示例看懂课堂上的操作节奏。
3. 套用玩法后，把真实玩法模板带入输入框，并补充自己的教学内容生成新课件。

## 3. 最高版本模板规则

读取 `sourceRefs[0]` 时，必须执行最高版本规则：

1. 先定位当前文件所在目录。
2. 如果同目录存在同名基础文件和 `_v数字.md` 文件，取版本号最大的文件。
3. 将最终采用路径写回 `sourceRefs[0]`。

## 5. 首页推荐逻辑

### 5.1 默认展示

1. 默认tab为“精选”。
2. 默认年龄为“全部年龄”。
3. `featured` = 41条玩法按 `priority` 降序取前16条。
4. 每屏展示8条。
5. 点击“换一换”展示下一批8条，到末尾后循环。

### 5.2 分类筛选

1. 非精选tab：按 `playway.category === 当前tab` 过滤。
2. 年龄筛选：解析 `ageText` 中的数字范围，只要玩法年龄范围和当前年龄段有交集，就展示。
3. 无结果：展示空态，不影响输入框。

伪代码：

```ts
const byTab = activeTab === 'featured'
  ? playways.sort(byPriority).slice(0, 16)
  : playways.filter(item => item.category === activeTab);

const visible = byTab.filter(item => hasAgeOverlap(item.ageText, activeAgeBand));
const batch = getCycledBatch(visible, batchIndex, 8);
```

## 6. 套用玩法实现

### 6.1 输入框结构

套用后，不再把全部提示词塞进普通textarea，而是展示结构化草稿：

1. 教学内容输入区：老师主要填写区域。
2. 已套用玩法摘要：展示玩法名、类型、年龄、课堂流程、可替换内容。
3. 生成提示词预览：默认折叠，展开展示 `templatePrompt`。

### 6.2 回填文本格式

前端内部可继续使用纯文本协议，便于发送给现有生成链路：

```text
教学内容：{老师填写的教学内容}

<已套用玩法>
玩法名称：{title}
玩法类型：{typeLabel}
适用年龄：{ageText}
适合内容：{suitableFor}

课堂互动流程：
1. {classFlow[0]}
2. {classFlow[1]}
...

可替换内容：
{replaceableContent}

玩法要求：
{templatePrompt}

本次生成要求：
1. 保留上方“教学内容”里的年级、学科、知识点或老师补充要求。
2. 只把互动玩法切换为「{title}」，不要丢失老师已经输入的内容。
3. 按该玩法生成可直接课堂使用的互动课件，包含明确题目、操作方式、正确反馈、错误提示和完成总结。
</已套用玩法>
```

### 6.3 切换玩法规则

1. 提取当前文本中 `教学内容：` 后、`<已套用玩法>` 前的内容。
2. 新玩法套用时，保留该教学内容。
3. 删除旧的 `<已套用玩法>...</已套用玩法>`。
4. 写入新玩法块。
5. 当前卡片显示“已套用”。

## 7. 看玩法示例实现

1. 点击“看玩法示例”后，用 `createPortal` 渲染到 `document.body`。
2. 遮罩层级必须高于侧边栏和灵感助手。
3. iframe 使用只读HTML，不提供下载、打开新窗口、编辑、一键同款。
4. 所有41条玩法都应有示例入口；`exampleId` 指向4个示例之一。
5. 文案必须用用户视角，不写“兜底映射”“复用同类”。

## 8. 画面风格实现

### 8.1 入口

1. 首页不展示风格模块。
2. 需求确认卡“画面和反馈”模块提供“调整画面风格”快捷选择。
3. 生成后的课件卡片提供“调整画面风格”按钮，只允许最新版操作。

### 8.2 选择逻辑

1. 基础风格15选1，必选。
2. 增强质感9个，可不选，可多选。
3. 最终生成prompt = 基础风格prompt + 所选增强prompt。
4. 用户侧展示 `displayName/name` 和 `visualFeatures/desc`，不展示内部来源名。
5. 风格弹窗里基础风格展示16:9参考图，支持查看大图。
