# 视频互动课件：编辑资源音色清单与交互说明

更新：2026-10-24。名单来源：Jolin 于 2026-10-23 提供的 22 个 MiniMax 音色。当前状态：已实现并通过本地交互验证；本次随 2026-10-24 发布更新到原线上 Demo。发布结果见 docs/releases/20261024 及需求目录中的交付核验记录。

## 本次范围

入口为视频互动课件「编辑资源 → 音频资源 → 重新合成」，场景资源编辑复用同一入口。首次生成流程及普通互动课件的音色选择保持原样。

按钮锚定的加宽下拉列表采用「语言 → 类型 → 点击音色合成」，两种语言、三种类型。第二级保留：每组仅 3～5 个候选，便于快速比较，避免一次展示 22 项。儿童是年龄分组，男声/女声是成人分组，儿童组不再增加男/女筛选层。

## 交互规则

1. 打开时，若当前 Voice ID 在清单内，回显其语言、类型和选中状态；兼容原 Demo 的已知别名。未知历史音色不自动替换，需用户明确选择。
2. 顶部切换语言与类型，音色两列平铺，每项展示名称和一句简短介绍；分类字号为 14px；切换筛选不触发合成。无第二层遮罩、弹窗标题栏、头像卡片和底部确认区。
3. 点击音色卡片即收起下拉并为当前音频创建候选；沿用「使用此音频 / 取消 → 确认全部替换」流程。点击外部、再次点击触发按钮、Esc 或滚动外层列表均收起下拉；Esc 不关闭资源编辑弹窗。
4. 采用后保存精确 provider Voice ID、展示名及语言码；为当前音频单独关联音色，不修改其他使用同一说话人配置的音频。共用该音频的场景仍遵循现有资源引用范围。
5. 切换语言仅更换合成语言/音色选项，不翻译配音文本。

## 接入与验证边界

- 英音分类沿用本次用户筛选结果。MiniMax [系统音色列表](https://platform.minimax.io/docs/faq/system-voice-id)可核对部分 ID 和英文名称，但未逐项标注英美口音。上线前需通过业务实际使用的平台核对全部 ID 可用性及样音口音。
- 主人公应优先试听儿童候选；旁白优先试听成人男女候选。名称与介绍按用户分组、官方名称语义及教学用途整理；介绍属于产品侧用途建议，并非真实样音测评。未自行添加高低音、语速、年龄数值或默认推荐。
- 当前 Demo 的重新合成为既有交互模拟，复用原准备音频；本轮未接入真实 TTS，未使用原音频冒充新音色试听。平台样音未取得，真实试听待接入。
- 历史课件 HTML 不变、无迁移。修改仍通过既有资源采用和生成新版本流程生效，旧版本继续运行。
