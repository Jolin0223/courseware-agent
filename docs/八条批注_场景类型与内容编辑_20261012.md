| **1—2. 场景列表简化。** 移除每场的内容摘要。以互动、视频、视频＋互动三张默认图表示类型，同一类型复用同一张图；保留场景名称、类型、编辑入口和已编辑保存标记。默认图与具体课件封面无关。 | ![场景列表](reviews/20261012-scene-content-types/01-scene-list.png) |
| **3. 纯互动编辑。** 模块名称统一为“本场景互动内容”。说明文案明确：修改描述可调整 AI 生成的本场景 H5 页面，请描述页面布局、互动操作与反馈，保存后随整课统一生成。 | ![互动内容编辑](reviews/20261012-scene-content-types/02-interactive-editor.png) |
| **4. 纯视频编辑。** 隐藏原“本场景内容”整个模块，也不校验隐藏的旧内容字段。直接编辑视频提示词、时长、首尾帧及配音，不增加从场景摘要再生成视频描述的步骤。 | ![视频内容编辑](reviews/20261012-scene-content-types/03-video-editor.png) |
| **5. 每段视频独立配置。** 只有一段时显示“本场景视频内容”；有多段时显示“本场景视频内容01 / 02 …”。每段独立配置“视频画面描述提示词”、首帧、尾帧和配音。添加/移除配音只影响当前视频的配音配置，不自动改写提示词；仍可通过“插入素材”或 @ 主动引用素材。 | ![多视频独立配置](reviews/20261012-scene-content-types/04-multiple-video-config.png) |
| **6. 视频＋互动编辑。** 同时显示“本场景互动内容”和“本场景视频内容”模块，分别描述互动页面与视频。修改互动描述不覆盖已填写的视频提示词。 | ![混合场景编辑](reviews/20261012-scene-content-types/05-mixed-editor.png) |
| **7. 教师工具入口随画布缩放。** 入口按钮使用 1920×1080 坐标中的 184×56 尺寸，与课件内容一起等比缩放，避免小预览中按钮占比过大。 | ![缩放后的教师工具入口](reviews/20261012-scene-content-types/06-scaled-teacher-trigger.png) |
| **8. 教师工具展开为四分之一面积。** 左下角面板固定使用 960×540 画布坐标，即宽高各为画布一半；与画布同时缩放。两列展示场景，保持悟空配色与字体，无整屏遮罩。顶部课件设置继续控制入口显示。 | ![1920画布中的教师工具](reviews/20261012-scene-content-types/08-teacher-full-canvas.png) |
