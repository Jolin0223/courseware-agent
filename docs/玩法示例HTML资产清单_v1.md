# 玩法示例 HTML 资产清单 v1

## 一、当前实现口径

本次先把「智慧跳跃-拼音启蒙」「口算赛车」「单词伪装者」做成 3 个可点击、可反馈、可推进的 16:9 示例 HTML。

重要说明：

1. 这 3 个示例已按 `creative-shrimp-suite-v1.0/workspace/GAME-VAULT/templates-ready` 下对应 md 的视觉框架、交互机制和题面数据重做。
2. 当前 HTML 里先用 CSS 绘制高质量占位画面，已经比纯按钮样机更接近课堂展示效果。
3. 要达到“精美课件示例”级别，还需要补齐下方图片资产，尤其是背景、角色和关键游戏元素。
4. 图片资源不能只写“16:9 或透明底 PNG”。背景、角色、平台、赛车、字母素材的尺寸和比例要求不同，详见下方规格；拿到图片链接后，研发替换 CSS 变量或对应元素即可，不需要重写交互逻辑。

## 三、生图通用要求

| 项 | 要求 |
| --- | --- |
| 背景画幅 | 横版 16:9，建议 1920x1080 或 2560x1440；必须无文字、无按钮，关键视觉不要压在顶部导航、底部操作区和右侧说明区 |
| 角色/道具画幅 | 透明底 PNG，不强制 16:9；建议按素材形状出方图或横图，画面四周保留 8%-12% 安全留白，避免裁切 |
| UI贴片画幅 | 透明底 PNG；平台、卡片、答案泡泡等建议横向素材，便于直接贴到 HTML 元素上 |
| 风格 | 圆润糖果 3D 粘土 / 儿童教育游戏 / 明亮低龄友好 |
| 禁止 | 不要真实品牌 logo，不要竞品角色，不要复杂成人化 UI，不要文字按钮 |
| 预留 | 背景图中央或下方必须留出游戏操作区域，避免关键元素被 UI 遮挡 |
| 输出 | 背景图用 JPG/PNG；角色、平台、赛车、字母素材建议透明底 PNG |

## 六、为什么还需要图片

这三个 HTML 已经按创意虾 md 还原了玩法结构，但“精美课件示例”的关键差异在图片资产：

| 没有图片时 | 有图后 |
| --- | --- |
| CSS 能表达布局、颜色、交互，但会像高保真原型 | 背景、角色和道具会有完整儿童 App 质感 |
| 老师能理解玩法，但代入感有限 | 老师能直观看到“这就是可上课的互动课件” |
| 适合内部评审逻辑 | 更适合领导评审和对教研展示 |
