# 首页权限等待与入口展示

线上 Demo：[有权限，等待6秒](https://coursewareagent.chenjialing.cn/?demoVideoAccess=slow-on) / [无权限，等待6秒](https://coursewareagent.chenjialing.cn/?demoVideoAccess=slow-off)。

给开发的说明：进首页先查视频制作权限，入口行和输入区先用骨架屏占位。有权限显示视频互动课件按钮，无权限就在同一位置显示互动课件说明。三种状态卡片保持同高，避免按钮出现时页面跳动。上下骨架同色、同步动画，标题、机器人和推荐区直接显示。Demo里的6秒只是模拟，实际接口返回就结束加载。

无权限文案：互动课件：知识点游戏、知识讲解、演示教具、空间展示、课堂气氛...

- 说明行：18px浅灰蓝叠层图标，轻量文字，无边框、点击或悬停效果。
- 入口骨架：单个圆角块；与下方建议占位共用颜色/透明度；1.5秒同步明暗变化。尊重减少动态效果偏好。
- 等待时：表单不可操作；推荐仍可试玩，一键同款/套用暂时禁用。
- 查询失败或10秒超时：卡片内提示重试，不按无权限处理。
- 宿主可通过`__COURSEWARE_FEATURE_ACCESS__`提供权限，或通过`__LOAD_COURSEWARE_FEATURE_ACCESS__()`提供异步查询。同页面共用查询；真实宿主权限优先于演示参数。生成接口仍须独立鉴权。
- 模拟参数只在开发环境及本项目正式/Pages演示域名生效。`slow-on`和`slow-off`均模拟6秒，`error`模拟首次失败，`timeout`模拟超时；`on`/`off`仅用于直接看最终态。
- 沿用`main`推送触发Cloudflare Pages自动部署，项目`courseware-agent`；构建`npm run build`，输出`dist`。

- 验证：`DEMO_BUILD_DIR=dist node scripts/check-permission-loading-browser.mjs`验证正式构建；去掉`DEMO_BUILD_DIR`验证线上域名。覆盖桌面/窄屏、两种权限、同色同步动画、布局位置、宿主权限优先级和重试。
