## 1. 本版结论

本版首页「灵感推荐区」P0 只使用 `creative-shrimp-suite-v1.0/workspace/GAME-VAULT/templates-ready/action/INDEX.md` 中登记的正式动作竞技模板。

核心口径：

1. 首页分类 = `精选` + action 真实 8 类。
2. 首页玩法池 = INDEX 中正式登记的 40 条模板。
3. 目录中存在但未进入 INDEX 的补充/实验文件，不进入 P0 首页。
4. 同一个模板存在基础版和 `_v数字` 高版本时，`templatePrompt` 取最高版本全文。
5. 用户侧不展示 `sourceRefs`、内部目录、内部能力包名称；这些只用于研发追溯。

## 2. 为什么不是语文/数学/英语分类

首页灵感推荐区的定位是“帮老师选互动玩法”，不是资源库。如果优先按语文、数学、英语分类，老师会以为这里是在找成品课件或学科资源，和「一键同款」区分度不够。

因此 P0 按真实模板库中的玩法机制分类：跳跃、竞速、找物、协作、生存、对战推理、解谜、淘汰晋级。老师先选“课堂互动动作”，再在输入框里补自己的教学内容。

## 4. 年龄筛选

## 5. 版本取用规则

研发入库或后端同步时必须执行最高版本规则：

1. 以 INDEX 中的文件为基准定位目录。
2. 如果同目录下存在同名 `_v数字.md` 文件，取数字最大的版本。
3. `sourceRefs[0]` 写最终采用路径。
4. `templatePrompt` 写最终采用文件全文。

示例：

| INDEX 文件 | 实际采用文件 |

| `001_障碍跳跳跳_拼音启蒙_蛋仔风_6-10岁.md` | `001_障碍跳跳跳_拼音启蒙_蛋仔风_6-10岁_v4.md` |

## 10. 前端使用规则

1. 默认展示 `featured`，按 `priority` 取前 16 条，每屏展示 8 条。
2. 点击“换一换”在当前筛选结果内循环切换下一批。
3. 非精选 tab 按 `playway.category === 当前tab` 筛选。
4. 年龄筛选按 `ageText` 数字范围做交集判断。
5. 点击“套用玩法”后，输入框保留老师已填教学内容，只替换 `<已套用玩法>...</已套用玩法>`。
6. 生成提示词预览必须展示 `templatePrompt` 的 markdown 渲染结果，不能展示原始星号格式。
